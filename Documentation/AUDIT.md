# VOLNA — аудит проекта

**Дата:** 12 ноября 2026  
**Ветка:** `feature/open-music-catalog`  
**Версия:** 1.0.0

## Цель аудита

Привести существующий репозиторий в рабочее состояние: убрать имитации функций, подключить реальные открытые каталоги, обеспечить честные лицензии и воспроизведение через AVPlayer, подготовить сборку IPA в GitHub Actions.

---

## Что было исправлено

### Провайдеры и поиск

- Jamendo переписан на реальные endpoints; лицензия и разрешение на скачивание берутся из ответа для каждого трека. Для кириллических запросов добавлен `lang=ru`.
- Internet Archive: поиск ограничен элементами с `licenseurl:*`; добавлен разбор метаданных, выбор MP3/M4A, изоляция ошибок, поддержка массивов в полях JSON.
- Wikimedia Commons: используется `videoinfo` и `derivatives`; для OGG/Opus выбирается официальная MP3-транскодия, чтобы AVPlayer мог воспроизводить файл.
- Добавлен Openverse как дополнительный агрегатор с фильтром `jamendo,wikimedia_audio`.
- Добавлен `DirectMusicProvider` и `DirectAudioValidator`: HTTPS, статус, Content-Type, редиректы, Range, размер, таймауты. HTML не принимается.
- Удалён устаревший экран статуса провайдеров, который показывал только декоративные состояния.
- Добавлен каталог источников `MusicSourceCatalog` с реальными описаниями, лицензиями и ограничениями.

### Модель данных и лицензии

- Лицензия хранится на уровне трека и потока; после дедупликации выбирается трек с известной открытой лицензией.
- Разрешения на поток и скачивание разделены.
- Неизвестный текст лицензии больше не превращается в «свободную» лицензию: `LicenseParser` возвращает `.unknown`.
- Для Public Domain без `LicenseUrl` используется `LicenseShortName`.
- Исправлена пара «лицензия + ссылка» при объединении треков из разных источников.

### Поиск и русский язык

- Параллельный поиск по всем включённым источникам; ошибка одного источника попадает в `issues`, но не отменяет остальные.
- Дедупликация по нормализованным исполнителю/названию с кластеризацией по длительности; несколько потоков сохраняются.
- Ранжирование учитывает играбельность, лицензию, обложку, длительность, совпадение с запросом и русскоязычность.
- Транслитерация кириллицы, варианты запроса, фильтры языка и жанра.
- Настройка «русский приоритет» реально передаётся в `SearchFilters` и влияет на ранжирование.
- Explicit-метка показывается только при включённой настройке; Openverse `mature` маппится в `Track.explicit`.

### Плеер

- Только AVPlayer, без сторонних аудиобиблиотек.
- Очередь, следующий/предыдущий, seek, shuffle, repeat, восстановление состояния.
- `AVAudioSession` с фоновым режимом, `MPNowPlayingInfoCenter`, `MPRemoteCommandCenter`.
- Обработка прерываний и смены аудиомаршрута.
- Сохранение состояния в JSON.

### Медиатека и настройки

- Избранное, плейлисты, история — JSON в Documents.
- Настройки — UserDefaults.
- Прямые ссылки — отдельный JSON-файл, проверка перед добавлением.
- Нет SQLite, Core Data, SwiftData, Realm, Firebase, Supabase и серверной части.

### UI

- Экраны: Home, Search, Artist, Album, Playlist, Player, Queue, Lyrics, Library, Favorites, History, Settings, Sources, Direct Links, Licenses.
- Все пункты меню ведут к реальным экранам; декоративных кнопок без действий не добавлено.
- App Icon 1024×1024 без альфа-канала, AccentColor и BackgroundColor в asset catalog.

### Тесты и CI

- Добавлен `VOLNATests`: лицензии, языки и транслитерация, дедупликация и ранжирование, аудиоформаты, прямая ссылка с неизвестной лицензией, LRC-парсер.
- `project.yml` приведён к Swift 5 language mode, iOS 17, iPhone-only, без SPM-пакетов.
- `build.yml`: XcodeGen, сборка под симулятор, выбор доступного iPhone-симулятора, unit-тесты.
- `ipa.yml`: unsigned IPA при отсутствии signing secrets, signed IPA при их наличии, артефакт и GitHub Release по тегу.
- Удалены мёртвые зависимости и несуществующий тестовый таргет из прежней конфигурации.

### Документация

- README, BUILD и PROVIDER_STATUS переписаны под фактическое состояние.
- Удалены устаревшие отчёты Stage 2 и research-файлы, которые описывали несуществующие функции.
- Добавлены этот аудит и отчёт о русскоязычном поиске.

## Осознанные ограничения

- Нет регистрации, аккаунтов, синхронизации между устройствами и серверных рекомендаций.
- Нет скачивания треков в приложение: отображается разрешение и ссылка, но менеджер загрузок не реализован.
- Нет офлайн-кэша аудио.
- Нет CarPlay и iPad-интерфейса.
- Нет интеграции с MusicBrainz и Navidrome; они не нужны для базового сценария.
- Поиск Openverse ограничен анонимным лимитом.
- Некоторые источники недоступны без обхода защиты; такие источники не подключены.

## Безопасность

- В коде допустим только публичный Jamendo Client ID `b488b912`.
- Jamendo Client Secret, токены, пароли и сертификаты не должны попадать в репозиторий или IPA.
- Signing-материалы передаются только через GitHub Secrets.
- Приложение не содержит WebView, произвольного JavaScript и удалённой базы данных.
- Прямые ссылки проверяются по HTTP-заголовкам; HTML отклоняется.
