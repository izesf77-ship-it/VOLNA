# VOLNA — каталог и легальные источники

**Обновлено:** 13 ноября 2026
**Версия приложения:** 1.0.0

## 1. Что такое каталог VOLNA

Каталог VOLNA — это не выдуманная витрина и не база «популярных исполнителей». Это
локальный снимок реальных релизов из публичного Jamendo API, которые:

- имеют прямой MP3-поток, воспроизводимый AVPlayer;
- пришли с обложкой, названием, исполнителем и альбомом;
- имеют известную открытую лицензию Creative Commons;
- прошли единые правила качества и дедупликации.

Приложение не переименовывает треки, не подставляет демо-записи и не создаёт
«рекомендации» из случайных файлов. Если API не вернул музыку, экран честно
показывает пустое состояние или ошибку.

## 2. Как формируется каталог

`CatalogService` выполняет несколько параллельных выборок публичного Jamendo API:

| Выборка | Параметры | Назначение |
|---|---|---|
| Русское популярное | `lang=ru`, `order=popularity_month`, до 200 | «Русская волна», популярное |
| Русские новинки | `lang=ru`, `order=releasedate_desc`, до 200 | «Новинки», новые релизы |
| Глобальное популярное | `order=popularity_month`, до 100 | «Популярное сейчас» |
| Русский рэп | `lang=ru`, `search=русский рэп`, до 80 | жанровая полка |
| Рок | `lang=ru`, `tags=rock`, до 80 | жанровая полка |
| Поп | `lang=ru`, `tags=pop`, до 80 | жанровая полка |
| Электроника | `lang=ru`, `tags=electronic`, до 80 | жанровая полка |
| Инди | `lang=ru`, `tags=indie`, до 80 | жанровая полка |
| Фолк | `lang=ru`, `tags=folk`, до 80 | жанровая полка |
| Классика | `lang=ru`, `tags=classical`, до 80 | жанровая полка |
| Джаз | `tags=jazz`, до 80 | жанровая полка |

Все запросы используют `audioformat=mp32`, `include=licenses musicinfo` и
`imagesize=600`. Ошибка одной выборки не ломает остальные: соответствующая полка
просто не появляется.

### Почему «Новинки» строятся из русской ленты

Публичный Jamendo API периодически отвечает пустым списком `results` на валидный
запрос — это наблюдалось у `popularity_month`, `releasedate_desc` и жанровых
тегов при повторных одинаковых запросах. Пустой ответ не означает, что музыки
нет. `CatalogService` делает до трёх попыток на каждую выборку; только после них
полка может остаться пустой.

«Новинки» используют русскую ленту `releasedate_desc`, потому что она
соответствует фокусу приложения и стабильно возвращает русскоязычные релизы.
Дубли с «Русской волной» и чартом отсекаются, а одна пластинка не занимает всю
полку: у каждого исполнителя в «Новинках» не больше двух треков.

### Правила качества

`CatalogQuality` применяет одинаковые правила к каталогу и поисковой выдаче:

- отсекает служебные файлы: `demo`, `test`, `track 07`, `song.mp3`, подкасты,
  караоке, минусовки и записи без названия/исполнителя;
- не считает кавером обычную песню с названием вроде «Cover Me»;
- убирает дубли по исполнителю, названию, ремастерам и изданиям;
- требует для редакционных полок открытую лицензию, обложку, альбом, поток и
  длительность от 60 секунд;
- сохраняет `UNKNOWN` как `UNKNOWN` и не выдаёт неизвестную лицензию за свободную;
- поднимает в сортировке свежие релизы, русскоязычные записи и треки с полными
  метаданными.

### Хранение и обновление

- Снимок каталога сохраняется в `Documents/VOLNA/catalog.json`.
- Отдельной базы данных, сервера, аккаунта и облака нет.
- Кэш считается устаревшим через 12 часов; обновление можно запустить вручную в
  настройках.
- Если обновление не удалось, показывается сохранённый снимок и честное
  сообщение об ошибке.

## 3. Что проверено живыми запросами

Проверки выполнялись через публичный API из Windows 12–13 ноября 2026 года:

- `lang=ru` + `popularity_month` — до 200 реальных русскоязычных треков;
- `lang=ru` + `releasedate_desc` — до 200 реальных русскоязычных треков;
- жанровые теги `rap`, `rock`, `pop`, `electronic`, `indie`, `folk`, `classical`
  и `jazz` возвращали реальные релизы;
- повторные одинаковые запросы иногда возвращали `0` при статусе `success`,
  поэтому в клиенте есть повторные попытки;
- аудиофайлы Jamendo отдают `audio/mpeg` и поддерживают Range-запросы.

Эти проверки подтверждают доступность API и метаданных. Они **не** подтверждают
воспроизведение на физическом iPhone — см. раздел 6.

## 4. Крупные каталоги, которые не подключены

VOLNA не использует закрытые методы, обход DRM, hotlink и парсинг страниц.
Поэтому основные российские и мировые каталоги остаются вне приложения, пока нет
легального публичного доступа к полному потоку.

| Сервис | Что доступно | Почему полный поток не подключён |
|---|---|---|
| **Яндекс Музыка** | Нет официального публичного API для сторонних плееров | Закрытые методы требуют OAuth и договора с правообладателями; полный стриминг без лицензии невозможен |
| **VK Музыка** | Публичный Audio API закрыт для новых сторонних клиентов | Нужно лицензионное соглашение с VK и правообладателями |
| **Zaycev.net** | Сайт и приложение сервиса | Публичного API для сторонних плееров нет; музыка лицензирована для собственного сервиса |
| **SoundCloud** | API с регистрацией приложения; часть треков доступна авторам | Большая часть записей — `all rights reserved`; stream endpoint не даёт права на стороннее распространение |
| **Deezer** | Публичный API метаданных и 30-секундные превью | Полный поток — только Premium/партнёрам через SDK и авторизацию |
| **Apple Music / iTunes** | iTunes Search API: метаданные и 30-секундные превью | Apple Music API требует MusicKit, developer token и подписку пользователя |

Эти ограничения также показаны пользователю в разделе «Источники» внутри
приложения. Они не являются «заглушками»: соответствующих провайдеров нет в
поиске, и приложение не делает вид, что умеет их воспроизводить.

## 5. Лицензии и права

- Лицензия хранится на уровне трека и потока, а не назначается всему каталогу.
- CC BY и CC BY-SA требуют атрибуции; приложение показывает доступную атрибуцию.
- CC BY-NC и CC BY-NC-SA ограничивают коммерческое использование.
- Разрешение на поток (`isStreamAllowed`) и на скачивание (`isDownloadAllowed`)
  хранятся отдельно.
- `UNKNOWN`, `Other` и `Restricted` не считаются открытыми лицензиями.
- Jamendo Client Secret в проекте отсутствует; используется только публичный
  Client ID `b488b912`.

## 6. Ограничения проверки

- Сборка и unit-тесты выполняются в GitHub Actions на macOS.
- Скриншоты Home, Search, Library и Player снимаются в iOS Simulator в CI.
- Локальной сборки на Windows нет.
- Проверка на физическом iPhone, фонового аудио, экрана блокировки, Control
  Center и прерываний не выполнялась.
- Неподписанная IPA собирается автоматически; для установки нужна собственная
  подпись и учётная запись Apple.
- Наличие конкретного мейнстримного исполнителя в каталоге не гарантируется:
  открытые каталоги не равны крупным лицензионным сервисам.

## 7. Правила добавления источника

1. Есть официальный публичный API и условия, допускающие клиентский доступ.
2. Есть прямой аудиопоток, который воспроизводит AVPlayer, или официальная
   транскодия.
3. Для каждого трека известна лицензия; неизвестная не выдаётся за свободную.
4. Не требуется обход Cloudflare, Referer, DRM, robots.txt или авторизации.
5. Ошибки источника изолированы и не ломают остальные.
6. Живые проверки и честный статус добавлены в документацию.
